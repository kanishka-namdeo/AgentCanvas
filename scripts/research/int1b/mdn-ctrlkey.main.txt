KeyboardEvent: ctrlKey property

 
 
 
 
 Baseline
 

 Widely available

 
 
 
 
 
 
 
 
 
 

 
 
 
 This feature is well established and works across many devices and browser versions. It’s been available across browsers since July 2015.

 
 
 - 
 
 See full compatibility
 
 

 - 
 
 Learn more
 
 

 
 

 
 
 The KeyboardEvent.ctrlKey
 read-only property returns a
boolean value that indicates if the control key was pressed
( true
) or not ( false
) when the event occurred.

 When the Control key itself is pressed or released, this property is true
 for its keydown
 event and false
 for its keyup
 event, because both events fire after the state change.

## Examples 
 
 html 
 <p>
 Press any character key, with or without holding down the CTRL key.<br />
 You can also use the SHIFT key together with the CTRL key.
</p>
<pre id="output"></pre>

 js 
 const output = document.getElementById("output");

function showChar(e) {
 output.textContent = `Key KeyDown: "${e.key}"
CTRL key KeyDown: ${e.ctrlKey}
`;
}

document.addEventListener("keydown", showChar);
