 What's the feature?

 For whatever reason, my muscle memory wants scrolling up on the scroll wheel (actually, Magic Mouse on a Mac) to zoom into the canvas (objects get larger). I know everyone has their own preference though, so I'd suggest just adding a user preference that is "Invert zoom direction".

 I think I'm used to it from that pinching out causes my index finger to move up, which is the same finger that would move the "scroll wheel" on a magic mouse. For what it's worth, the Maps app on macOS agrees with me, though Photos does not.

 Where would you like this feature?

 This issue has been reopened as it remains unaddressed.

 Summary

 The feature requested in this issue has not been implemented despite comprehensive camera options being added in PR #3282 .

 Analysis

 The current TLCameraOptions
 interface includes controls for:

 
 panSpeed
: Adjust pan sensitivity

 zoomSpeed
: Adjust zoom sensitivity

 wheelBehavior
: Choose between zoom, pan, or none

 
 However, there is no invertZoomDirection
 or equivalent option to reverse the scroll zoom direction.

 Current behavior

 
 Scrolling UP on scroll wheel: Zooms OUT

 Scrolling DOWN on scroll wheel: Zooms IN

 
 Requested behavior

 
 Option to INVERT this direction (like macOS Maps, Apple Photos)

 
 Why this matters

 The current behavior doesn't match the muscle memory of users familiar with:

 
 macOS Maps and Photos apps

 Pinch gestures on touch devices (pinching out = index finger moving up)

 Many mapping applications

 
 Implementation Path

 
 Add invertZoomDirection?: boolean
 to TLCameraOptions

 Update zoom calculation logic in Editor.ts
 to respect this option

 Add tests and documentation

 
 This is a reasonable UX preference that aligns with established patterns in other applications.
