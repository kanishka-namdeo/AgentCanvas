The tldraw SDK provides several approaches: automatic local persistence with a single prop, manual snapshots for custom storage backends, and a migration system for handling schema changes. Local persistence The simplest approach is the persistenceKey prop. This automatically saves to IndexedDB and syncs across browser tabs: import { Tldraw } from &#x27; tldraw &#x27; import &#x27; tldraw / tldraw . css &#x27; export default function App () { return ( &lt; div style ={ { position : &#x27; fixed &#x27; , inset : 0 } } &gt; &lt; Tldraw persistenceKey = &quot; my - document &quot; /&gt; &lt;/ div &gt; ) } Copy Each unique key represents a separate document. Two editors with the same key share the same document and stay synchronized. Snapshots For custom storage backends, use getSnapshot and loadSnapshot to save and restore editor state as JSON: import { getSnapshot , loadSnapshot } from &#x27; tldraw &#x27; // Save const { document , session } = getSnapshot ( editor . store ) await saveToDatabase ( document ) // Load const document = await loadFromDatabase () loadSnapshot ( editor . store , { document }) Copy The snapshot has two parts: document (shapes, pages, bindings) which you typically save to a server, and session (camera, selection, UI state) which you keep per-user locally. See Persistence for complete coverage of snapshots, async loading with TLStoreWithStatus , and auto-save patterns. The store The editor&#x27;s store is a reactive database that holds all records. You can create a standalone store, load data into it, and pass it to the editor: import { useState } from &#x27; react &#x27; import { createTLStore , loadSnapshot , Tldraw } from &#x27; tldraw &#x27; export default function App () { const [ store ] = useState (() =&gt; { const store = createTLStore () const saved = localStorage . getItem ( &#x27; my - drawing &#x27; ) if ( saved ) { loadSnapshot ( store , JSON . parse ( saved )) } return store }) return &lt; Tldraw store ={ store } /&gt; } Copy See Store for details on store operations, listening to changes, queries, and transactions. Multiplayer sync For real-time collaboration, use the @ tldraw / sync package. Multiple users can edit the same document simultaneously, see each other&#x27;s cursors, and follow each other&#x27;s viewports: import { useSyncDemo } from &#x27;@ tldraw / sync &#x27; import { Tldraw } from &#x27; tldraw &#x27; export default function App () { const store = useSyncDemo ({ roomId : &#x27; my - room - id &#x27; }) return &lt; Tldraw store ={ store } /&gt; } Copy See Collaboration for production setup, custom presence, authentication, and building custom sync solutions. Migrations When you load a snapshot from an older schema version, the store migrates it automatically. For custom shapes, you can define migrations to handle changes to their props over time. See Persistence for details on shape props migrations and general migrations.
