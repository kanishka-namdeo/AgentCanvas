 Installation

 How to install Radix Colors.

 npm 
 

 Install Radix Colors from your terminal via npm, yarn or pnpm. Current version is 3.0.0

 # with npm 

 npm install @radix-ui/colors

 # with yarn 

 yarn add @radix-ui/colors

 # with pnpm 

 pnpm add @radix-ui/colors

 

 
 

 CDN
